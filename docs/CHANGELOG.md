## [v5.3] - 2026-09-14

### 新增
- 桌宠皮肤扩展为 9 款，加入概念图中的小海鸥、奶油猫和像素机器人，并适配正常、疲劳、休息和关闭状态。
- 桌宠从设置页拆分为独立导航页面，加入动态大预览、皮肤卡片、启停控制、陪伴状态和休息进度展示。
- 桌宠新增“捏一捏、拉长长、挠痒痒、抛一下、轻戳”五种互动玩法，支持阻尼回弹、抛掷落地、粒子反馈、双击彩蛋与模式持久化。
- 默认玩法设为“自由移动”，左键拖动可调整桌宠位置；切换到互动玩法后使用 `Shift + 拖动`移动，避免拖动手势冲突。

### 变更
- CareEyes Pro 主程序与 Windows EXE 元数据升级至 v5.3。

## [v5.2] - 2026-09-09

### 新增
- 桌面宠物（DesktopPet）：纯 QPainter 绘制，跟随护眼状态切换表情；脚下进度条显示距离下次休息的进度；支持戳一戳反应、拖动贴边、位置记忆；右键菜单含“打开主界面 / 立即休息 / 切换护眼 / 藏起来 / 退出”；托盘与设置页均可开关，状态写入配置。
- 顶部紧凑导航替代宽侧边栏，界面占用更小、信息密度更高。
- 系统指标采集：CPU/内存/运行时间（WinAPI，非管理员时降级为不可用），统计页展示。
- 精简 PyInstaller 构建配置（`CareEyesPro.spec`、`build.ps1`）与 Windows 版本信息（`version_info.txt`）。
- 护眼监控与统计增强（`26b2ade`）。

### 修复
- 安全 Gamma 恢复与空闲感知调度（`d1f4f36`）：退出/异常时按记录恢复原始 Gamma 曲线；空闲暂停不累计工作时长；全屏检测顺延休息 5 分钟，并区分白名单（不推迟）/ 强制推迟（如 javaw.exe）。
- 配置写盘改为“临时文件 + 原子替换”，降低异常退出导致的配置损坏。

### 移除
- 去除未使用的 `pywin32` 依赖；`requirements.txt` 收敛为 `PyQt5`、`pynput` 两项。
- 清理废弃文件与缓存（`ce69051`）。

### 已知问题
- Gamma 修改对部分独占全屏程序/管理员程序无效，需以管理员身份运行。
- 显卡驱动更新或系统恢复默认可能覆盖 Gamma，需重新开关护眼。
